# 2026-04-02 V3.6.5 发布说明

## 版本定位

- 本次为 `V3.6.5`
- 属于小版本修复发布，不涉及数据结构、同步协议或页面流程改造。

## 更新内容

- 修复站内页面切换到趋势页时，旧页会闪出一帧的问题。
- 为共享站内导航新增统一离场压屏机制，避免浏览器直接切页前先露出旧页面。
- 修复看板、记录、趋势、历史、设置五个页面的运行时文案模块静态占位先露出的问题。
- 保留并收口历史页“下一站，山海相见”等同类运行时文案模块的首屏 gate。
- 同步升级页面标题、设置页可见版本标识、`manifest.webmanifest`、`app.js` 版本常量、`supabase/setup.sql` 默认版本值与 `service-worker.js` 缓存键。

## 验证摘要

- `node --check app.js` 通过。
- 本地静态服务 + Playwright Headless 已验证：
  - `看板 -> 趋势`
  - `记录 -> 趋势`
  - `历史 -> 趋势`
  - `设置 -> 趋势`
  - 四条路径均已先出现 `app-page-leaving`，再发生 URL 切换。
- 禁用 JS 的浏览器检查已确认五个页面运行时文案组初始均隐藏。

## 发布提示

- `service-worker` 缓存键已从 `jiageyouba-v364-cache-v1` 升级到 `jiageyouba-v365-cache-v1`。
- 推送后建议在手机端重点复查：
  - 快速切到趋势页时是否还会看到旧页一帧
  - 历史页累计支出下方文案模块是否还会闪出旧句子
  - 客户端是否正确切换到 `V3.6.5`
