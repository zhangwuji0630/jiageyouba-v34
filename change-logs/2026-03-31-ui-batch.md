## Findings Before Changes

- The save area spacing on the record page was larger than the gap between the main modules.
- The trends detail rows did not have click handlers.
- The trends page only summarized the current natural month, which explained why a February repair entry did not show while a March one did.
- The cloud sync inputs rendered as white-on-white in dark mode at runtime.
- The history page had no delete interaction.
- The dashboard already had enough data to compute cost per kilometer.

## Implementation Notes

- `add.html`
  - Added a top horizontal record-kind strip with `加油 / 维修 / 保养 / 洗车 / 配件`.
  - Reduced the first card padding, heading spacing, odometer font size, and fuel input block spacing to make the fuel module materially shorter.
  - Removed the extra save-wrapper top padding and tightened form spacing so the save gap matches the main module gap.
  - Added wash-only `精选 / 普洗` buttons.
- `app.js`
  - Added primary record-kind routing separate from legacy `decoration` support so old data remains editable.
  - Added `isOdometerRequiredKind()` and switched add-page validation/visibility so only `fuel` and `maintenance` require and show odometer.
  - Added wash-type metadata and storage under `record.payload.washType`.
  - Reworked stats detail rows to navigate to filtered history URLs and changed detail summaries to use `analytics.allRecords` instead of current-month-only records.
  - Added history filtering by `?kind=...` and long-press delete with confirmation.
  - Added dashboard cost-per-distance calculation plus dynamic mini-card layout injection.
  - Added vehicle-art selection logic based on vehicle name and cloud-auth UI collapsing logic.
- `settings.html`
  - Reworked the current-car card into a quote-card-style image card with a right-side artwork slot and cyan gradient overlay.
  - Added a stable `cloudSignedOutPanel` wrapper so the auth form can collapse cleanly at runtime.
- `app.css`
  - Added stronger input styling plus autofill overrides for cloud inputs.
  - Added long-press history-card feedback and current-car artwork styling hooks.
- `assets/vehicle-art`
  - Added three local SVG artworks: `coupe-blue.svg`, `offroad-blue.svg`, and `sedan-blue.svg`.
