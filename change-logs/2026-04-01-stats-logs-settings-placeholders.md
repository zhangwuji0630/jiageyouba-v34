# 2026-04-01 趋势历史设置页静态占位修复

## 范围

本次仅处理三个页面仍残留的静态占位问题：

- 趋势页首屏统计与分类明细会先露出演示值。
- 历史页会先露出示例累计金额与示例记录卡。
- 设置页会先露出示例车辆、示例里程、示例同步时间与默认云同步状态。

## 实际改动

- `stats.html`
  - 将趋势页首屏统计与分类明细默认值改为安全初始值。
  - 为趋势页关键数据区增加 page hydration gate，避免真实数据写入前露出演示值。
- `logs.html`
  - 将历史页累计支出默认值改为 `0.00`。
  - 删除静态示例记录卡，改为空列表容器，等待 `renderHistoryList()` 注入真实内容。
  - 为累计金额与记录列表增加 page hydration gate。
- `settings.html`
  - 将当前车辆、备用车辆、同步时间、云同步状态的静态演示文案改为安全占位。
  - 为车辆卡片、同步时间与云同步区增加 page hydration gate。
- `app.js`
  - 新增通用 `setPageHydrated()`，在趋势页、历史页、设置页各自渲染完成后解除 gate。
  - 设置页改为在 `renderCloudAuthState()` 完成后再解除 gate，避免先露出错误登录态。
- `app.css`
  - 新增非看板页面的通用 hydration gate 隐藏规则。

## 验证

- 已执行 `node --check app.js`，通过。
- 已确认三页原有的静态演示值与历史示例卡已从目标 HTML 中清除。
- 尚未做浏览器人工回归；需要继续确认三页首屏是否只在真实数据到位后显示。
