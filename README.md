# 加油记录 V3.4

一个基于 5 个移动端页面整合而成的静态 PWA：

- `index.html` 看板
- `add.html` 记录
- `stats.html` 趋势
- `logs.html` 历史
- `settings.html` 设置

## 当前能力

- 5 页底部导航可直接跳转
- 支持安装为 PWA
- 本地 `localStorage` 保存加油记录
- 看板 / 趋势 / 历史会根据记录自动刷新
- 设置页支持单位切换、车库信息编辑、CSV/JSON 导出、JSON 备份恢复

## 说明

- 当前版本保持原始 UI 视觉不变，主要补齐了 PWA 外壳和核心交互
- 主题暂固定为深色
- 保养 / 洗车 / 维修 / 配件等模块目前仍为展示位，尚未建立独立数据模型
